# 📚 StudyMate AI

StudyMate AI is a beginner-friendly AI-powered study assistant built using Python, Streamlit, and Ollama.

## ✨ Features

- 📘 Topic Explainer — Understand topics in simple language.
- 📝 Quiz Generator — Generate practice questions.
- 📄 Notes Summarizer — Summarize study notes.
- 🗂️ Flashcard Generator — Create revision flashcards.
- 📅 Study Planner — Organize your study sessions.

## 🛠️ Technologies Used

- Python
- Streamlit
- Ollama
- Llama 3.2 (1B)

## 🚀 How to Run Locally

1. Install Python.
2. Install Ollama and download the model:

   `ollama pull llama3.2:1b`

3. Install the required Python packages:

   `python -m pip install streamlit ollama`

4. Run the application:

   `python -m streamlit run app.py`

## 🎯 Purpose

This project was created to explore Generative AI and build a practical tool to support students in their daily studies.

## ⚠️ Note

This application runs locally and requires Ollama and the selected model to be installed. It is not a publicly hosted web application.
